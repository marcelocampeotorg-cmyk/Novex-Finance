# SKILL 09 — Estética e UX Premium

Documento principal: `12_UX_UI_IDENTIDADE_VISUAL.md`.

## Antes de mexer em UI
Inspecionar as duas imagens oficiais fornecidas e a identidade visual do repositório.

## Direção
Dark-first premium, NOVEX, ciano controlado, grafite/obsidian, hierarquia forte.

## Evitar
- template genérico;
- excesso de glow;
- cards demais;
- termos técnicos na home;
- números fictícios;
- gráficos decorativos;
- candlestick;
- sidebar lotada.

## QA
Desktop e mobile. Dados reais. Estados loading/empty/error. Sem overflow.
