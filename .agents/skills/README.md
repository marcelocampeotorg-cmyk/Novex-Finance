# Skills Oficiais — NOVEX Finance

Estas skills substituem a coleção antiga. Não manter skills conflitantes ativas.

## Regra
Toda skill aponta para documentos normativos. Skill não cria requisito novo; ela define **como o agente deve trabalhar** sobre o requisito já documentado.

## Ordem mínima antes de trabalhar
1. `SKILL_00_LEITURA_DA_DOCUMENTACAO.md`
2. `SKILL_01_CONTROLE_DE_ESCOPO.md`
3. skill específica da área
4. `SKILL_16_EVIDENCIA_DE_CONCLUSAO.md`

Erros novos sempre ativam também `SKILL_02_REGISTRO_DE_ERROS.md`.
