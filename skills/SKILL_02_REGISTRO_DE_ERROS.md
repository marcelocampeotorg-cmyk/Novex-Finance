# SKILL 02 — Registro de Erros

Documento: `docs/ERROR_LOG.md`.

## Quando usar
Sempre que encontrar:
- bug;
- falha de segurança;
- migration inconsistente;
- mock em produção;
- divergência documentação x código;
- teste enganoso;
- integração não comprovada;
- regressão.

## Procedimento
Registrar antes de “esquecer” o problema. Não transformar hipótese em fato. Atualizar o mesmo ID até resolução.

## Encerramento
Só marcar RESOLVIDO com:
- correção identificada;
- teste/regressão;
- evidência;
- commit quando aplicável.
