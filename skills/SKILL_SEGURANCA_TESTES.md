# Skill — Segurança e testes

## Objetivo

Impedir vazamento, acesso cruzado, duplicidade e atualização financeira incorreta.

## Regras

- autorização server-side;
- tokens criptografados;
- validação de webhook;
- idempotência;
- rate limit;
- uploads validados;
- testes de isolamento;
- testes de concorrência;
- logs redigidos;
- evidências antes de concluir.
