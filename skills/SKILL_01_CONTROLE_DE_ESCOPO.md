# SKILL 01 — Controle de Escopo

Documentos: `01_VISAO_PRODUTO.md`, `02_REGRAS_INEGOCIAVEIS.md`, `21_DECISOES_CONFIRMADAS.md`.

## Regra
Não implementar “porque seria legal”, “porque a API suporta” ou “porque é padrão de mercado”.

## Especialmente proibido sem mudança documental aprovada
- refund;
- payout;
- transferências;
- multiusuário;
- trading/candlestick;
- ERP/fiscal/estoque;
- LLM central;
- novas integrações bancárias.

Se uma melhoria útil surgir, registrar como proposta fora da implementação atual.
