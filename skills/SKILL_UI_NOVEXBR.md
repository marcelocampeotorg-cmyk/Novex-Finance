# Skill — UI NOVEXBR

## Objetivo

Transformar as imagens em componentes reais, legíveis e responsivos.

## Método

1. Ler identidade visual oficial.
2. Criar tokens.
3. Criar shell reutilizável.
4. Implementar componentes.
5. Montar páginas.
6. Validar 1920, 1366 e mobile.
7. Comparar visualmente.

## Não fazer

- usar screenshot como background;
- copiar upsell, CNPJ ou dados fictícios;
- improvisar logo;
- usar `!important` global;
- criar página monolítica;
- esconder erro com CSS.

## Pronto quando

Todas as páginas são navegáveis, legíveis, têm estados reais e o preview está disponível.
