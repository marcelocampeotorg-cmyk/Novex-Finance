# SKILL 05 — Conciliação Inteligente

Documentos: `08_MOVIMENTACOES_E_CONCILIACAO_INTELIGENTE.md`, `09_AUTOMACAO_RECORRENCIAS_E_CATEGORIAS.md`.

## Objetivo
Maximizar autonomia sem inventar certeza.

## Método
Combinar evidências. Evitar `if nome == X && valor == Y` como regra universal.

## Resultado
- alta confiança: automática;
- média: sugestão;
- baixa: pendente.

Toda regra aprendida precisa poder ser explicada, editada e desativada.
