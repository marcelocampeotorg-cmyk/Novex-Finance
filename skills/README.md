# Guias de skills do projeto

Estes arquivos são guias operacionais para o agente de desenvolvimento. Não são plugins nem substituem as capacidades nativas da ferramenta.

## Skills

- `SKILL_ARQUITETURA_PRODUTO.md`: transformar decisões em arquitetura simples.
- `SKILL_UI_NOVEXBR.md`: implementar a interface com fidelidade e acessibilidade.
- `SKILL_DOMINIO_FINANCEIRO.md`: preservar integridade monetária e de parcelas.
- `SKILL_MERCADO_PAGO.md`: integrar por adapter, webhook e sync.
- `SKILL_CONCILIACAO.md`: ligar movimentos reais a contas previstas.
- `SKILL_DOCKER_DEVOPS.md`: ambiente reproduzível e publicável.
- `SKILL_SEGURANCA_TESTES.md`: segurança, isolamento e evidências.

O agente deve usar todas as skills relevantes por marco, sem inventar funcionalidades fora do escopo.
